# The HUD scenes, played by both clients against the same fresh vanilla server
# (scripts/measure_hud.py): the real 1.20.1 client through
# scripts/hud_oracle.java, ours through `ov_voxel --hud-script`. Both read this
# file, so both see the same commands in the same order.
#
#   cmd <command>        a Chat Command, without its slash
#   wait <ticks>         client ticks
#   shot <name>          <name>.png with the HUD, <name>-nohud.png without it
#                        (the exact background, so the HUD's ink is a
#                        difference and not a guess), then the facts
#   key <tab|f3> <press|release|tap>
#   look <yaw> <pitch>   the camera, in degrees
#   tabfoot <header json> | <footer json>
#                        Set Tab List Header And Footer, which no vanilla
#                        command sends: the real client gets it through its own
#                        setters, ours through its own decoder (docs/provenance/hud.md)
#
# Straight up at a noon sky with clouds off: every pixel that is not sky is the
# interface's.
